常見問題

本專案與私人局專案有何不同？

本頁突出金幣大廳、玩法選擇和 Unity UI 程式碼；私人局專案侧重組局、俱樂部牌桌和場景資料。

從哪個文件了解用戶端介面？

從 LuaUIObject.cs 入手，再閱讀列表和表格适配器，了解 C# 與 Lua 介面的連接方式。
